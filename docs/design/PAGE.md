# Страница дизайн-системы

> Раньше это была отдельная страница приложения по адресу `/design`: живой
> образец компонентов, который тянул демонстрационные данные. Из продукта она
> убрана — дизайн-система описана здесь, в документации. Актуальный исходник
> компонентов: `frontend/src/components/`.

## Зачем страница убрана из приложения

- В приложении нет демо-данных: всё общение с backend идёт через API, а страница
  витрины держала отдельный мок-модуль `__shared__/mock/finance.ts`.
- Витрина компонентов нужна при разработке, а не пользователю. Отдельный
  маршрут без авторизации светил внутренности интерфейса.
- Внешний вход в продукт теперь ведёт на страницу возможностей `/features`,
  а не в витрину.

## Что описывает этот документ

| Раздел | Где смотреть в коде |
| --- | --- |
| Токены цвета, типографика, радиусы | `frontend/src/styles/globals.css`, `tailwind.config.ts` |
| Кнопки, поля, переключатели | `frontend/src/components/ui/` |
| Карточки, KPI, суммы | `frontend/src/components/data/` |
| Графики | `frontend/src/components/charts/charts.tsx` |
| Стеклянные поверхности | `frontend/src/components/glass/` |
| Иконки категорий | `frontend/src/__shared__/utils/category-icon.tsx` |
| Макеты и референсы | `docs/design/MOCKUPS.md`, `docs/design/refs/` |

## Принципы

1. **Семантические токены, а не палитра.** Компоненты используют
   `text-fg-primary`, `bg-surface-2`, `border-stroke-subtle` и подобные имена.
   Тема (светлая/тёмная) меняет значения токенов, а не классы в разметке.
2. **Один инстанс интерактива.** Диалог записи, тосты и меню живут в корне
   приложения: их открывают разные экраны, дублировать состояние нельзя.
3. **Мобильный размер — 390 px.** Любая сетка проверяется на этой ширине;
   панели складываются в столбик, второстепенное уходит вниз.
4. **Доступность.** У иконочных кнопок есть `aria-label`, у графиков —
   текстовое описание, у форм — подписи и подсказки об ошибках.

## Витрина при разработке

Если нужен живой образец компонентов, страницу можно временно вернуть в
`frontend/src/app/main.tsx` как отдельный маршрут вне продакшена. Готового
файла в репозитории больше нет: описания выше достаточно, чтобы собрать
образец из существующих компонентов без мок-данных.
