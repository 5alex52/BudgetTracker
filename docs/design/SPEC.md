# BudgetTracker — дизайн-спецификация «Liquid Glass»

Документ описывает визуальный язык и технические решения фронтенда: палитру, материал стекла,
типографику, сетку, компоненты, анимации. Основа — 7 референсов из `docs/design/refs/`.

---

## 0. Как читались референсы и что из них берём

### 0.1 Метод

Референсы разобраны двумя независимыми способами, чтобы формулировки не были догадками:

| Способ | Инструмент | Что даёт |
|---|---|---|
| OCR с боксами (Apple Vision, ru+en) | `tools/imginspect2.swift` | весь текст, точные нормализованные координаты каждого блока |
| Цвет/геометрия по пикселям | `tools/imginspect2.swift` (`--grid`, `--segments`) | точные hex поверхностей, границы панелей, радиусы, отступы |
| Смысл и структура | vision-модель через `@liustack/modlens` | роли регионов, состояния контролов, что читается неоднозначно |

Замеры сделаны в предположении **DPR = 2** (изображения 3544×1986 → окно 1772×993 CSS px).
Отсюда все «измеренные» CSS-значения ниже.

### 0.2 Важное: чей это UI

Референсы — скриншоты реального продукта (**wallet by BudgetBakers**, `web.budgetbakers.com/ru-RU/…`).
Оттуда берём **структуру и информационную архитектуру**, но не бренд: логотип, название, шрифты и
фотографии чужие. Продукт в этом репозитории называется **BudgetTracker**.

Из референсов берём: состав экранов, иерархию, расположение блоков, набор контролов, формат данных
(суммы с валютами, мультивалютность, группы по датам, %-изменения по месяцам).

Из референсов **не берём**: плоскую «тёмную» тему без стекла (в референсе стекла нет вообще — это
подтвердил разбор: «no clear blur or translucency»), чёрный фон `#000000`, плотную типографику 12–13 px,
чужие иконки и лого.

### 1.3 Фон под стеклом (обязательное условие эффекта)

Стекло на однотонном фоне выглядит «серой заливкой». Поэтому под плавающим слоем всегда лежит
насыщенный фон из 3–4 радиальных пятен + тонкий шум. Слой `GlassBackdrop` — `position: fixed`, `z-index: 0`,
`pointer-events: none`, 3–4 `radial-gradient` на всю площадь:

| Тема | Пятно 1 | Пятно 2 | Пятно 3 | Пятно 4 |
|---|---|---|---|---|
| Dark | `#0FA968` @ 42 %, α .42, сверху-слева | `#1E6FD9` @ 78 %, α .30, справа | `#7B3FE4` @ 12 %, α .22, снизу | `#00B3A4` @ 92 %, α .18 |
| Light | `#37C98A` α .35 | `#5AA9FF` α .28 | `#B79BFF` α .22 | `#8CE0C8` α .24 |

Крупные размытые пятна (`blur` через сам градиент, без `filter: blur()`), контент поверх — на
непрозрачных `--surface-*`, поэтому пятна видны только через стекло навигации и в зазорах.

### 1.4 Контраст (проверено для худшего случая — стекло над самым насыщенным участком пятна)

## 2. Материал стекла: `GlassSurface`

Один примитив с вариантами и тремя уровнями прогрессивного улучшения.

### 2.1 Токены (`src/styles/theme.css`, единственное место с параметрами)

```css
:root {
  /* уровни размытия */
  --glass-blur-sm: 10px;   /* чипы, сегменты, мелкие поповеры */
  --glass-blur-md: 20px;   /* навбар, тулбар, таб-бар */
  --glass-blur-lg: 34px;   /* модал, sheet, сайдбар */

  --glass-radius-sm: 14px;
```

### 2.2 Уровень 1 — базовый (все браузеры)

```css
.glass {
  position: relative;
  isolation: isolate;
  background: var(--glass-bg-regular);
  -webkit-backdrop-filter: blur(20px) saturate(165%) brightness(1.06);
  backdrop-filter: blur(20px) saturate(165%) brightness(1.06);
  border: 1px solid var(--glass-border);
  border-bottom-color: var(--glass-border-bottom);
  box-shadow: var(--glass-highlight), var(--glass-shadow-md);
  border-radius: var(--glass-radius-md);
}
```

Правила уровня 1:
- Для `-webkit-backdrop-filter` значения пишутся **буквально**, без `var()` — Sass/PostCSS-переменные в
  этом свойстве ломаются на Safari (см. §2.5).
- `border` вместо `outline`: обводка участвует в лэйауте и не съедается `overflow: hidden`.
- Внутренний блик — только `inset box-shadow`, без псевдоэлементов, чтобы не создавать лишний слой
  композиции на каждом стекле.
- `isolation: isolate` — чтобы `mix-blend-mode` для блика за курсором (уровень 3) не «протекал».

### 2.3 Уровень 2 — SVG-рефракция (только Chromium, через feature-detect)

Техника: `backdrop-filter: url(#glass-refract)` c `feTurbulence` + `feDisplacementMap`, отрисовка в
`sRGB`. Искажение применяется только по краевой зоне (маска из `feImage`/`feComponentTransfer`),
центр остаётся чистым — иначе текст «плывёт».

```html
<svg class="glass-filters" aria-hidden="true" width="0" height="0">
  <filter id="glass-refract" x="0" y="0" width="100%" height="100%"
          color-interpolation-filters="sRGB">
    <feTurbulence type="fractalNoise" baseFrequency="0.008 0.008" numOctaves="3" seed="17" result="noise"/>
    <feGaussianBlur in="noise" stdDeviation="2" result="blur"/>
    <feDisplacementMap in="SourceGraphic" in2="blur" scale="14"
                       xChannelSelector="R" yChannelSelector="G"/>
  </filter>
</svg>
```

Feature-detect (не по UA-строке):

```ts
// Chromium поддерживает url()-фильтр в backdrop-filter; Safari/Firefox — нет.
export const supportsRefraction = (): boolean => {
  if (typeof CSS === 'undefined' || !CSS.supports) return false;
  if (!CSS.supports('backdrop-filter', 'url(#f)')) return false;
  // Safari принимает синтаксис, но не применяет: проверяем, что filter реально уважается
  return CSS.supports('color-interpolation-filters', 'sRGB');
};
```
Дополнительно результат фиксируется один раз и кладётся в `data-refraction="on|off"` на `<html>`, класс
`.glass--refract` включается только при `on` **и** при ширине элемента ≤ `--glass-refract-max-w`.
Вне Chromium — молчаливый откат на уровень 1, никаких ошибок в консоли.

### 2.4 Уровень 3 — взаимодействие

- Пружина при нажатии: `transform: scale(.975)` c `spring(stiffness 380, damping 30, mass .9)`.
- Блик за курсором (опция, по умолчанию — только для `sidebar`, `dialog`, `tabbar`):
  `radial-gradient(220px circle at var(--mx) var(--my), rgba(255,255,255,.18), transparent 60%)`
  на псевдоэлементе; координаты обновляются через `requestAnimationFrame`, не чаще 60 Гц.
  Псевдоэлемент создаётся только у элементов с `data-glass-glow="true"`, чтобы не плодить слои.
- Никакой анимации `blur` — только `opacity` и `transform` (см. §9).

### 2.5 Откаты и спецрежимы

| Условие | Поведение |
|---|---|
| `@supports not (backdrop-filter: blur(1px))` | плотный фон `--surface-1`, обводка 1 px, без блика |
| `prefers-reduced-transparency: reduce` | `--glass-bg-*` → непрозрачный `--surface-1`, `backdrop-filter: none` |
| `prefers-contrast: more` | обводка 1.5 px `--text-primary` α .40, фон стекла плотнее на шаг, тени убраны |
| `prefers-reduced-motion: reduce` | пружины → `ease-out 120ms`, `scale` при нажатии отключён, блик за курсором отключён |
| Ширина элемента > 800 px | рефракция не применяется (только blur) |
| `forced-colors: active` | `border: 1px solid CanvasText`, фон `Canvas` |

### 2.6 Вложенные радиусы

Правило: **внутренний радиус = внешний − padding**.

```css
.card        { border-radius: var(--glass-radius-md); padding: 12px; }
.card__inner { border-radius: calc(var(--glass-radius-md) - 12px); }
```

Готовые пары: `28/20/16` для больших поверхностей, `20/14/8` для средних, pill + chip = pill.
В токенах: `--radius-outer`, `--radius-inner`, `--radius-inset` на каждый уровень.

### 2.7 Где стекло разрешено

Только плавающий и навигационный слой:

| Стекло | Не стекло |
|---|---|
| верхнее меню (`NavBar`) | карточки виджетов дашборда |
| мобильный `TabBar` | списки записей и счетов |
| `Sidebar` фильтров | таблица аналитики |
| `Dialog` / `Sheet` / модал записи | KPI-цифры и графики |
| `Popover`, `Dropdown`, `Menu`, `Tooltip` | формы настроек (только инпуты — `surface-2`) |
| `SegmentedControl`, `Switch`, `Slider` | баннеры и пустые состояния |
| `Toast`, плавающая кнопка `FAB` | — |

Правило «не стекло на стекло»: внутри `Sidebar` контролы используют `surface-2` с полупрозрачностью
`.5`, а не собственный `backdrop-filter`. Внутри `Dialog` — то же. Допустимое число одновременно
видимых стеклянных поверхностей: **≤ 6** (навбар + сайдбар + тулбар + сегмент-контрол + 2 поповера).

## 3. Типографика

### 3.1 Подключение

`medeo-font` (npm, `1.0.0`), self-host, без CDN.

```
public/fonts/medeo/            ← файлы, скопированные из node_modules при сборке (vite-плагин/скрипт)
```

- `@font-face` с `font-display: swap`, `font-named-instance`/`font-feature-settings` по README пакета;
- `preload` только основного начертания Medeo Sans (`wght 400`) — остальные грузятся по требованию;
- `unicode-range` для кириллицы, если пакет разбит на сабсеты;
- `font-optical-sizing: auto` на `body`;
- Medeo Mono — суммы, таблицы с цифрами, ID, время;
- Medeo Pixel **не используем**;
- Fallback: `-apple-system, system-ui, sans-serif`.

```css
:root {
  --font-sans: 'Medeo Sans', -apple-system, system-ui, sans-serif;
  --font-mono: 'Medeo Mono', ui-monospace, -apple-system, system-ui, monospace;
}
body { font-family: var(--font-sans); font-optical-sizing: auto; -webkit-font-smoothing: antialiased; }
```

### 3.2 Проверка tabular-nums

Обязательный шаг перед версткой таблиц: рендер-тест в `src/design/` (страница `/design`, раздел
«Type check»), который выводит `1111111111` / `0000000000` и меряет ширину через `Range.getClientRects()`.
Если ширины расчатся — `font-variant-numeric: tabular-nums` не работает, и все цифры набираются
`--font-mono` принудительно (класс `.num`). Решение фиксируется в `docs/design/SPEC.md` (§5.4 после проверки).

### 3.3 Шкала

| Токен | Размер / интерлиньяж | Вес | Трекинг | Применение |
|---|---|---|---|---|
| `--fs-display` | 32 / 38 | 600 | −0.02em | заголовок логина, крупные KPI |

## 6. Анимации и переходы

| Токен | Значение | Применение |
|---|---|---|
| `--dur-instant` | 90 ms | нажатие, hover контролов |
| `--dur-fast` | 150 ms | появление подсказок, смена иконки |
| `--dur-base` | 220 ms | поповеры, сегменты, табы |
| `--dur-slow` | 320 ms | модал, sheet, сайдбар |
| `--ease-out` | `cubic-bezier(.22, 1, .36, 1)` | появление |
| `--ease-in-out` | `cubic-bezier(.65, 0, .35, 1)` | перемещение индикатора |
| `--spring-press` | `stiffness 380, damping 30, mass .9` | нажатие |
| `--spring-panel` | `stiffness 260, damping 26, mass 1` | модал, sheet |

Правила:
- Анимируем только `transform`, `opacity`, `box-shadow` (и `background-color` для ховера); **blur не анимируем**.
- Модал: `opacity 0→1` + `scale .96→1` + `translateY 8→0`, 320 ms `--spring-panel`; подложка — `opacity 0→1`, `backdrop-filter: blur(2px)` (статичный).
- Сегмент-контрол: пилюля едет `--ease-in-out 220ms` (layout-анимация через motion `layoutId`).
- Список записей: появление при скролле — без анимации (производительность), только `stagger` 24 ms на первые 12 элементов.
- `prefers-reduced-motion: reduce` — все пружины → `ease-out 120ms`, `scale` отключён, stagger отключён.

## 7. Доступность

- Полная работа с клавиатуры: `Tab` обходит навбар → сайдбар → контент; `Esc` закрывает слои; Radix
  берёт на себя focus-trap и `aria-*`.
- `:focus-visible` — 2 px `--accent`, offset 2, никогда не `outline: none` без замены.
- Скип-линк «К основному содержимому» первым табом.
- Все иконки-кнопки имеют `aria-label` (RU/EN через i18n).
- Таблица аналитики: `<table>` c `<th scope>`, суммы с `aria-label` в развёрнутом виде.
- `Amount` объявляется скринридеру как «−2 329,15 BYN», а не как «минус две тысячи…» — через `aria-label`.
- Контраст — таблица §1.4; при `prefers-contrast: more` усиливается.
- Цвет не единственный носитель смысла: доход/расход дублируется знаком и стрелкой (как в референсе).

## 8. Производительность

- Одновременно видимых стеклянных поверхностей ≤ 6 (проверяется в Playwright-тесте: подсчёт
  `[data-glass]` в вьюпорте).
- Рефракция — только на элементах ≤ 800 px и только в Chromium; никогда на всю ширину страницы.
- `backdrop-filter` не комбинируется с `filter` на том же элементе (двойное размытие = 2 прохода).
- Списки: виртуализация не нужна до 200 строк, но строки — `content-visibility: auto`.
- Изображения/иконки — SVG-спрайт Lucide, без иконочных шрифтов.
- Бюджет: LCP < 2 s, INP < 200 ms; проверка Lighthouse-пресетом в CI (позже, вне этого этапа).

## 9. Тёмная/светлая тема

- Источник: класс `.dark` на `<html>` (ручной переключатель, три состояния: светлая / тёмная / как в
  браузере), значение в `localStorage`, дефолт — `prefers-color-scheme`.
- `<meta name="color-scheme">` + `color-scheme: light dark` на `:root`, чтобы скроллбары и формы
  подстраивались.
- Скрипт инициализации темы — инлайн в `index.html` (до первой отрисовки), иначе мигание.
